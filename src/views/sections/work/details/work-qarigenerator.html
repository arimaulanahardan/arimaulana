Project Overview

QariGenerator needed a production-grade educational web platform designed specifically for students and professionals transitioning into AI, Data Science, and Machine Learning. The objective was to replace fragmented learning materials with an end-to-end interactive portal featuring modular curriculum management, automated coding exercise evaluations, and progress tracking.

As Lead Developer, I built a high-performance single-flow LMS using Laravel and Tailwind CSS, featuring streamlined registration, asynchronous video progress sync, and clean dashboard navigation — all delivered within a 2-month rapid development cycle.

Core Challenges & Architectural Solutions

  • Modular Course Engine: Dynamic lesson renderer supporting rich text, embedded live notebooks, downloadable resources, and auto-graded milestone quizzes.
  • Real-Time Progression Sync: Asynchronous backend listeners track student video watch time and checkpoint completion without page reloads.
  • Role-Based Instructor Portal: Granular permissions allowing instructors to review student assignments, view completion metrics, and manage cohort schedules.
  • Optimized Mobile First Experience: Crafted lightweight component layouts ensuring sub-2-second load times on mobile 4G networks across emerging markets.
