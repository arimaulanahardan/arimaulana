Project Overview

Himpunan Pengusaha Muda Indonesia (HIPMI) required a centralized, modern marketplace portal to connect hundreds of regional small and medium businesses (UMKM) with corporate buyers and investors. The challenge was building an e-commerce catalog that allowed instant product filtering, request-for-quote (RFQ) messaging, and merchant profile verification without the lag of traditional multi-page apps.

As Lead Architect, I designed and delivered this full-stack SPA marketplace in just one month, leveraging Laravel + Inertia.js + Vue.js to eliminate API overhead while retaining robust server-side validation and security.

Core Challenges & Architectural Solutions

  • Inertia.js SPA Architecture: Eliminated client-side API boilerplate while providing smooth instant client-side routing, retaining Laravel's robust server validation.
  • Faceted Search & Dynamic Filters: Implemented indexed database queries supporting multi-attribute filtering (region, price bracket, certification, MOQ) in sub-100ms response times.
  • Merchant Self-Service Dashboard: Provided business owners with drag-and-drop product uploads, stock management, and verified badge compliance tracking.
  • Direct Inquiry & RFQ System: Integrated direct buyer-to-seller inquiry workflows with WhatsApp API integration for instant transaction negotiation.
